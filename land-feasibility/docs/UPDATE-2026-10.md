# 2026-10 更新說明

這一版修的是使用者以「新北市三重區幸福段 1428、1428-1、1430-2、1430-3、1430-4 地號
（乙種工業區，5 筆合計 1,618 ㎡ ＝ 489.45 坪）」實際試算時發現的問題。
舊版算出每坪土地單價 234.7 萬元，新版同一塊地的出價上限（走人價）約每坪 28.9 萬元，
本區工業區土地實價登錄行情約每坪 67 萬元。

## 1. 舊版為什麼算錯

| 問題 | 原因 | 新版做法 |
| --- | --- | --- |
| 比價拿臺北市大安區路段 | 內建的比價案例是**合成的大安區示範資料**，不論輸入哪個縣市、行政區都用它（約 159 萬／坪） | 改用內政部實價登錄開放資料，22 縣市、368 個鄉鎮市區各自的預售、新成屋、成屋、土地與車位成交；只取本區、同產品型態 |
| 輸入「三重區」沒有差別 | 行政區是自由文字欄，引擎完全沒讀 | 改為「縣市 → 行政區」下拉；行政區決定比價資料、土地行情與新北市住宅區／商業區的容積率 |
| 工業區當住宅估 | 產品類型固定為住宅大樓 | 依分區自動判定：乙種工業區不得作住宅使用，以廠辦試算（單價取本區廠辦預售成交，三重區約 44 萬／坪） |
| 容積獎勵 12%「待查證」 | 預設採危老（綠建築 8% ＋ 耐震 4%），不管基地上有沒有老建物 | 先判斷制度前提：素地不能走危老與都更；工業區可走「工業區立體化」；自動採用可行組合中淨效益最高者 |
| 營建成本太低 | 固定 RC 13～25 層 17 萬／坪，沒有地下室單價 | 2026 年行情曲線：依產品與地上層數內插（住宅 20～40 萬、廠辦 18～29 萬），地下室 32 萬／坪另計；加計營業稅 |
| 成屋單價偏離 | 同上，比價資料是大安區 | 摘要另列本區新成屋與全部成屋行情供對照，採用單價則是本區同產品的預售成交 |
| 法規「算不出來」 | 日照、高度比、退縮、防火間隔、畸零地都標人工待補 | 每一項都依條文算出結果（見第 3 節），缺輸入時以明示的預設值試算並標示 |
| 新增地號後左欄卡住 | 左欄是 flex 容器，子區塊被壓縮且本身裁切 | 左欄可捲動，區塊不再被壓縮 |
| 只能拿到第二類謄本 | 解析器只認第一類 | 第一類、第二類都能解析；第二類的姓名與統編隱匿不影響面積、權利範圍與他項權利判讀 |

## 2. 名詞

- **出價上限（走人價）**：在目前的量體、售價、成本與時程假設下，剛好達到報酬目標
  （預設年化 IRR 15% 且稅後淨利率 15%，兩者取嚴）的最高土地總價。賣方開價超過這個數字就應該放棄（walk away）。
- **建議出價**：IRR 與淨利率目標各再加 3 個百分點回推的地價，是談判時的出價目標，留緩衝吸收假設誤差。
  舊版把這個數字叫「走人價」，而且它比出價上限低，名稱與意思相反，已更正。
- **本區同分區土地行情**：同縣市、同行政區、同分區類（住／商／工）土地成交的中位數；
  有百坪以上成交時優先用百坪以上的中位數（與整宗開發用地較可比）。
- **容積獎勵組合排行**：把本案可以走的開發制度（一般建照、工業區立體化、危老、都更）與各制度下可申請的獎勵項目
  全部排列組合，依「淨效益」排序。淨效益 ＝ 多出來的可售坪與車位收入 − 多蓋的營建費（整棟重算，含層數變多造成的單價上升與地下室）
  − 隨收入比例的管銷與稅費 − 取得獎勵的代價（容積價購、捐贈樓地板、標章設計增量）− 比一般建照多花的審議月數利息。
  不符前提的制度排在最後並寫出原因；點任一列就改用該組合。

## 3. 法規檢討（全部算出結果）

| 項目 | 依據 | 算法 |
| --- | --- | --- |
| 分區允許用途 | 都市計畫法各施行細則（乙種工業區不得作住宅使用） | 產品與分區不符時判不通過 |
| 畸零地 | 建築法第44、45條；各縣市畸零地使用規則 | 以全國最嚴標準（寬 7 m、深 20 m）檢核；未填寬深時以面積推估 |
| 臨路寬度 | 建築法第42、48條 | 8 m 以上通過；未填時以 8 m 試算並標低信心 |
| 退縮 | 建築法第48條；各細部計畫土管要點 | 新北市預設 4 m，檢查退縮後可建範圍是否容得下建蔽率面積 |
| 高度比 | 建築技術規則設計施工編第164條 | H ≤ 3.6 ×（Sw ＋ D），且 3.6：1 斜率陰影面積 ≤ L × Sw ÷ 2；在基地內試排標準層與層數找可行配置，放不下時縮減量體 |
| 日照 | 同編第39條之1 | 高度 21 m 以下或北側鄰地非住宅區、商業區者不適用；否則列出免檢討條件 |
| 防火間隔 | 同編第110條 | 防火構造建築物以外牆防火時效處理 |
| 停車 | 同編第59條 | 依用途類別（住宅、辦公、工廠）換算法定車位，與本區預售附車位比例推估的銷售需要取大 |
| 細部計畫但書 | 都市計畫法第22、32條 | 列出申請分區證明書時要核對的六件事 |

## 4. 資料來源

- **實價登錄**：內政部不動產成交案件實際資訊資料供應系統開放資料（成屋、預售屋、土地、車位），
  交易期間 2024-03～2026-09。已排除親友、員工、特殊關係與多戶合併交易；單價扣除車位價格與面積。
  由 `tools/build_lvr.py` 產生 `js/data/lvr/{縣市代碼}.js`，網站依縣市延遲載入（同站靜態檔，不呼叫外部 API）。
  建議每季重新產生一次；也可在「進階假設 → 售價」直接貼上實價登錄下載的 CSV 原檔。
- **縣市與行政區**：中華郵政郵遞區號（twzipcode-data 2.0.0），22 縣市 368 鄉鎮市區。
- **分區管制**：臺北市土地使用分區管制自治條例、都市計畫法新北市施行細則與各細部計畫、
  都市計畫法臺灣省施行細則（第18、32、34、34-3、34-5條）。
- **容積獎勵**：都市危險及老舊建築物加速重建條例與獎勵辦法、都市更新條例與獎勵辦法、
  都市計畫容積移轉實施辦法、建築技術規則第十五章（綜合設計）、新北市工業區立體化方案、新北市 TOD 增額容積。
- **營建成本與融資**：2025～2026 年雙北營建行情公開報導；中央銀行 2026 年 9 月 17 日理監事會（重貼現率 2%、
  刪除購地貸款切結動工規定，購買住商用地貸款最高五成）。
- **稅**：加值型及非加值型營業稅法（房屋部分 5%，土地免徵）、營業稅法施行細則第21條、所得稅法第24條之5。

## 5. 仍須注意

- 新北市住宅區、商業區的容積率依各細部計畫；表內為常見值，個案以土地使用分區證明書為準。
- 實價登錄樣本少的行政區會自動改用全市資料並標示；土地成交多為小面積或持分時，行情只作參考。
- 本系統的量體是概算，不是建築設計；出價前請建築師以實測地籍圖檢討。

## 6. 2026-10-05 追加：工業區都更、工業區變更與研究行情

使用者以三重乙種工業區、地上物屋齡 50 年的基地比對市場（溪尾街 TOYOTA 舊廠 2025-10 以每坪約 70 萬成交，
附近預售住宅 77～88 萬／坪），指出依「維持工業區、廠辦 44 萬／坪」算出的出價上限偏離市場。
差距來自市場以「工業區都更」或「變更為住宅、商業區」的潛力交易工業區土地，這一版把兩條路線與研究行情補上：

- **新北工業區都更**：都更制度加入新北「都更二箭」基準容積加給（基地 2,000 ㎡ 以上，臨路 20／30／40 公尺加給
  10／15／20%，須捐贈公益設施）與「都更一箭」捷運場站周邊增額容積（TOD，向市府價購）。
  參考案例：三重中興段工業區都更，容積率由 210% 提高到 462%，維持產業使用（智慧廠辦）。
- **工業區變更為住宅區／商業區**（左欄「開發路線」，限工業區）：依新北市都市計畫工業區變更審議原則，
  回饋比例住宅區 40%、商業區 44%（容積率高於內政部都委會第 662 次會議標準者；未超過者 37%／40.5%，本系統取較高者），
  以回饋後剩餘土地 × 新分區容積率計算，產品改為住宅，都市計畫變更審議另加 36 個月；土地行情仍以工業區比較。
- **研究行情**（左欄新區塊）：逐行輸入查到的新案開價、成交與土地交易（例：「住宅, 悅田吾澍, 77-88, 2026-09, 樂居」），
  同產品的研究行情優先於實價登錄中位數，土地研究行情優先於實價登錄土地中位數；實價登錄仍列在明細供對照。
- **大面積舊建物房地交易**：土地 300 坪以上、屋齡 30 年以上的整宗房地交易（含多筆合併登記），以總價 ÷ 土地坪數列為地價參考，
  例：三重溪尾街 2025-10，土地 903 坪、總價 6.08 億，每坪約 67.3 萬。

「先上網研究再出結果」已在第 7 節以混合模式完成（使用者自備 API 金鑰、按下才連網）。

## 7. 2026-10-06 追加：混合模式（貼上的證明書＋自動研究＋每週更新行情）

使用者要求：分區與細部計畫條文由使用者貼上（以該地號的正式文件為準），其餘能自動查的資料由系統查，讓結果更準。
三件事各自獨立，沒用到時網站行為與之前相同。

### 7.1 分區證明書／細部計畫（左欄新區塊，使用者貼上）

貼上「土地使用分區證明書」全文或細部計畫土地使用分區管制要點的條文，系統逐行解析並**優先於內建分區表**：

| 抓什麼 | 怎麼用 |
| --- | --- |
| 使用分區（含「部分○○區、部分道路用地」、各地號分區） | 取代左欄下拉的分區；分區表沒有的分區（產業專用區、公共設施用地…）以證明書為準 |
| 建蔽率、容積率（阿拉伯數字、全形、「百分之二百一十」皆可） | 取代分區表數值，信心為「輸入」並記錄原文行號；左欄手動輸入的仍優先 |
| 窄路容積率（「面前道路未達 8 公尺者容積率不得大於 200%」） | 路寬未達門檻時自動改用 |
| 細部計畫一次列多個分區的表格或條文 | 依證明書的分區（或左欄選的分區）挑出對應那一組 |
| 臨路退縮、高度或層數限制、開挖率、停車標準（每戶一位、每 100 ㎡ 一位…） | 進入法規檢討與量體：高度上限會壓低樓層並縮減量體，停車標準取代建技規則第59條，開挖率決定地下室每層面積 |
| 整筆公共設施用地的地號 | 自基準容積扣除（購地成本仍以全部面積計）；「部分」公設用地無法自動切分，列為注意 |
| 最小開發規模、捷運場站範圍、更新地區、不得作為容積移轉接受基地 | 最小規模不足判不通過；捷運範圍帶入 TOD 試算；更新地區適用時程獎勵；容積移轉限制使該項不適用 |
| 附帶條件、回饋捐地、都市設計審議、禁限建、土壤液化、文化資產等 | 列入「細部計畫但書」並出現在風險清單 |

含管制字詞但看不懂的行列在「含管制字詞但未解析」，不猜。

### 7.2 自動研究（左欄新區塊，使用者自備 Anthropic API 金鑰，按下才連網）

按「開始研究」後，瀏覽器直接呼叫 Claude（含網路搜尋與讀取網頁），
搜尋基地周邊新案開價與成交、同區土地交易，並逐項查核本系統的假設：單價、土地行情、車位價、去化、營建單價、
融資條件、容積獎勵制度、捷運距離、路寬。結果：

- **價格**寫進「研究行情」的自動研究區塊（可修改或刪除，重新研究時整段更新），收入段與土地比較改用研究值，
  但信心標為「中」（有來源、未經人工核對）；使用者自己輸入的行仍標「輸入」。
- **捷運距離、路寬、屋齡**只填入空白欄位（使用者已輸入的不動），並記錄來源；路寬由研究填入時信心降為「中」。
- **逐項查核**（相符／不符／查無）列在右欄「風險與待確認 → 公開資料查核」與報告，每項附來源網址。
- 每個來源網址都與本次實際搜尋、讀取到的網址比對；沒出現過的標「未比對」，避免把模型記憶當成查證。
- 分區與容積率不由研究決定，仍以貼上的分區證明書為準。

隱私與費用：送出前會列出要送的內容（縣市、行政區、地段、面積、分區、本系統的估價假設；地號需勾選才送），
不送謄本全文與所有權人。金鑰只存在瀏覽器（勾「記住」才寫入 localStorage），不進專案、不隨匯出檔帶走。
費用由使用者的 API 帳戶支付，通常每次約 1～3 美元，完成後顯示搜尋次數與估計費用。
請求啟用伺服器端備援（`fallbacks: "default"`）：Claude 因安全分類拒絕時，由 Anthropic 改用備援模型完成同一請求。

技術：官方 SDK（@anthropic-ai/sdk 0.131.0）事先打包為 `js/vendor/anthropic-sdk.js`，只在按下研究時延遲載入；
`index.html` 不載入它，平常開網站仍然零網路請求（`tools/checkall.sh` 第 4c 項檢查）。
Anthropic API 允許瀏覽器直接呼叫（含雙擊開啟的 file:// 頁面）。主機若設定 Content-Security-Policy，`connect-src` 需允許 `https://api.anthropic.com`。

### 7.3 每週自動更新實價登錄行情（GitHub Actions）

`.github/workflows/land-feasibility-lvr.yml` 每週三自動：下載內政部實價登錄本期與近 8 季開放資料（`tools/fetch_lvr.py`）→
產生各縣市行情檔（`tools/build_lvr.py`）→ 跑完整檢查（`tools/checkall.sh`）→ 行情有變動才提交 → 打包網站 zip 供下載部署。
筆數明顯不足（網站改版、下載失敗）時不提交。排程只在預設分支執行，合併到 main 後生效；也可在 Actions 頁面手動執行。
